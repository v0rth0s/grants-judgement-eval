# Argument Rating

How much should this argument change the verdict on the position?

| Rating | Anchor |
| --- | --- |
| 5 | Decisive. On its own it settles the question against (or for) the position. |
| 4 | Correct and important, but it depends on a condition or doesn’t settle this case. |
| 3 | Genuinely contested. Careful experts could disagree. |
| 2 | Relevant, but given more weight than it deserves. |
| 1 | True or plausible, but beside the point. |
